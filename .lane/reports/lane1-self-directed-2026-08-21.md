## Finding (tier 4-7: share-metadata completeness)

The generated head's Open Graph block is complete except one field: `og:url`.
The page declares `og:title`, `og:description`, the full `og:image` family
(alt/type/width/height), and the `twitter:*` set, but no `og:url`. Unfurlers
(Facebook, LinkedIn, and other Open Graph consumers) read `og:url` as the
canonical share URL used to deduplicate shares and resolve the preview object;
without it, shares of `https://inish.in/?<query>` or alternate spellings can
collapse to the request URL instead of the canonical root.

Verification that this was not already owned:

- No open PR covers it — checked `gh pr list` (15 open); PR #100-#104 (fonts
  cache, sitemap lastmod, Person knowsAbout, Person sameAs, Article schema
  image/description/dateModified) plus #88-#99 (docs/verification) all touch
  other files; `gh pr diff` for #100-#104 contains zero `og:url` references.
- No backlog item names `og:url` (`grep og:url` in the improvement-loop
  backlog and journal is empty).
- No git history for `og:url` on this repo (`git log --all -S "og:url"` empty).
- Live head today (2026-08-20): `curl -s https://inish.in/ | grep -c og:url` = 0.
