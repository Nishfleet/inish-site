AI Anthropic

Anthropic says Sonnet 5.5 runs 30% faster and finishes tasks for less

Anthropic shipped the second model in its 5.5 family, built for everyday work like fixing bugs and drafting documents. The company says it answers more than 30% faster than the version it replaces and does the same work using fewer tokens, the chunks of text these models bill you for. The price per token did not change.

Checked Anthropic says Sonnet 5.5 scores 70.6% on Terminal-Bench 4.0 against 10.3% for Sonnet 5, runs 30%+ faster, and still costs $2 per million input tokens.

Nish My agents run on Sonnet, so a cheaper task means a longer loop I can afford to run. I would still re-run my own jobs before I trust the saving.

But The benchmarks and the cost per task are both Anthropic's own measurements. Nothing about the per token rate moved, so a customer pays full price unless the model really does use fewer tokens.

Product ideas TechCrunch

Shopify now lets AI agents complete a purchase at checkout

Shopify turned on WebMCP for checkout, so an AI agent running inside a shopper's browser can read the checkout screen, change an address or delivery option, and place the order once the buyer approves it. It is going out to all eligible Shopify stores, including Shop Pay, while some retailers block agents from buying at all.

AMD is buying World Labs, the lab run by Fei-Fei Li, for $8.2 billion in stock

AMD has a definitive agreement to acquire World Labs, the San Francisco lab that builds AI models for understanding and simulating the physical world. The deal is all stock, so AMD keeps its cash, and World Labs keeps doing research afterwards. Li reports to AMD's chief executive as chief scientist.

Nvidia built a watchdog chip to keep AI agents in their lane

Nvidia announced a platform that puts a second, independent guard beside every AI agent. OpenShell, its open source software, decides what an agent is allowed to reach. The company lists Anthropic, Microsoft, Salesforce, Scale AI and SpaceXAI among the partners, and OpenAI is absent from the list.
