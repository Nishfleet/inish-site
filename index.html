AITechCrunch

Meta's coding agent works on several features at once

Meta released Muse Code in beta, a terminal tool for large software projects. It can plan changes, write code, check the result, and split a big job across smaller agents working in parallel.

Checked In testing, Meta said Muse Code built 6 game features at the same time without collisions.

Nish I care less about another coding-agent launch than the work model: Muse Code running 6 isolated jobs together could make overnight product work much more practical.

But It is still in beta, and the source does not show an independent benchmark against Codex or Claude Code.

Product ideasTechCrunch

AI search is sending Shopify stores more buyers

Shopify says AI search is adding traffic and orders instead of replacing traditional search. Its view is that AI agents understand a buyer's full constraint set, then send the buyer closer to the right product.

Checked Shopify said AI-driven traffic and orders to its stores rose 3x year over year in the second quarter.

Nish I would build Shopify pages that answer a real constraint, not pages that win one keyword. AI shopping is a distribution change and a merchandising test at the same time.

But This is Shopify's earnings-call account, reported by TechCrunch, so the result is not an independent measurement across all merchants.

Google says Demis Hassabis will become Chair of Google DeepMind and Chief Scientist of Alphabet while continuing to lead Isomorphic Labs. Google frames the change as a way to push both frontier AI and scientific work faster.

ToolsCloudflare

Cloudflare open-sources a controlled operating layer for agents

Cloudflare OS is an open platform for building internal apps and agent workflows around a company's own systems. The design puts small service-specific Gatekeepers between an agent and sensitive tools, so access can be narrowed and approvals can be required.

Checked Cloudflare says, "Cloudflare OS is available today" as open source and can be deployed into a customer's own Cloudflare account.

Nish For me, Cloudflare OS is the kind of infrastructure that matters: not another chatbot, but a way to turn company rules and permissions into reusable product behavior.

But The source is a product announcement, and the managed dashboard version is described as future work rather than a shipped service.

Demand signalsNeon

A small model matches a frontier model for search at 100 times lower cost

Neon and Castform describe a 4-billion-parameter open model trained to search company data through Neon's database tools. They say the approach matches GPT-5.6 Sol on their retrieval task while costing far less per request.

Checked Neon's example says a typical multi-step search with GPT-5.6 Sol costs about $0.03 and that the open model costs 100 times less.

Nish I see the business opportunity as more than a cheaper model. It is making private company data usable for training without forcing every search step through an expensive frontier model.

But The comparison is a company case study on a specific retrieval task, not a general claim that small models beat frontier models everywhere.

WildcardPromptArmor

A hidden instruction can make Atlassian Rovo leak company data

PromptArmor describes a zero-click attack against Atlassian Rovo. A hidden instruction in an uploaded file can cause the agent to send Jira or Confluence content to an attacker's website through a URL it opens itself.

Checked PromptArmor says it disclosed the issue to Atlassian on May 23, 2026, and published the report on August 5 after follow-ups.

Nish my Rovo security rule for every agent product is simple: a tool that opens a URL is still an outbound data channel, even when web search is switched off.

But The report is from the security researcher who found the issue, and it says Atlassian had not communicated a fix by publication.
