Editor’s note

AI & agentsGitHub

qm makes agent work a shared, scoped system

qm is a TypeScript harness for startups that gives each person and room its own scoped memory, files, permissions, crons, web apps, and durable sandbox. It keeps private and shared work separate while letting teams collaborate in Slack and on the web, and it can drive multiple agent harnesses instead of locking a deployment to one vendor.

Why read: A concrete architecture for moving an agent from one-person assistant to a company surface without making every memory, file, and permission global.

AI & agentsGitHub

Skill Recorder turns one observed task into a reusable procedure

Microsoft’s Skill Recorder captures a work session, reconstructs an intent plus ordered steps with Copilot CLI, and lets the user review that analysis before producing a SKILL.md procedure or scheduled Automation. It favors native agent tools such as gh or web_fetch over replaying clicks, so the recording can generalize beyond the original screen.

Why read: A useful pattern for turning tacit operating knowledge into reviewed procedures instead of leaving it trapped in a one-off screen recording.

Mu puts a broad tool surface behind one MCP endpoint

Mu exposes 67 tools for news, search, mail, markets, files, calendars, apps, and more through one MCP endpoint. The project emphasizes that the underlying services are real capabilities rather than wrappers around another catalog, and it can run as a hosted service or a self-hosted Go binary.

Why read: The single connection and authorization boundary gives agents a coherent tool surface while keeping the underlying services in one operator-controlled system.

Build & shipGitHub

WASTE makes storage bandwidth part of the inference design

WASTE is a dependency-free C engine for mixture-of-experts models that keeps the shared trunk in RAM and streams selected experts from NVMe. Its README reports running the full 2.78-trillion-parameter Kimi K3 on a 64 GB MacBook Pro at roughly 0.6 tokens per second, with a bounded cache trading speed against memory.

Why read: A clear systems lesson: a model that does not fit in RAM can become an I/O and caching problem rather than an automatic reason to give up.

Qwen Audio keeps the conversation open while work continues

Qwen Audio Agent is a real-time voice runtime designed to keep foreground conversation alive while a background agent uses tools or works through a task. The project supports ACP-connected agents, WebUI and terminal interfaces, a macOS desktop surface, task tracking, local profiles, and cross-session memory; its README lists Hermes among supported integrations.

Why read: A concrete interaction model for assistants that do not make the user choose between talking and waiting for work to finish.

Design & productGitHub

interior treats the half-second after a click as product infrastructure

Interior is a copy-in React collection of micro-interactions built around headless hooks and optional styled examples. Its design notes reserve space before state changes arrive, model motion after the physical event, treat keyboard input as a complete path, handle abandoned gestures, and preserve information when reduced motion is enabled.

Why read: A compact reminder that polish is not decoration: predictable transitions and complete input paths are part of whether an interface feels trustworthy.

Talivia packages revenue context into self-hosted analytics

Talivia’s open-source edition combines web analytics, Session Replay, collaborators, shared analytics, import/export, and revenue connections for Stripe, LemonSqueezy, Polar, Dodo, Yolfi, or manual payments. This CRM makes evidence quality a first-class data model

TryCompAI’s CRM is organized around a durable research agent rather than a chat box attached to a database. Incoming events become queued work, the agent decides what to investigate, and tools record observed evidence instead of guessing facts about people; weak evidence stays a human-reviewed suggestion.

Why read: A strong operational rule for founder systems: a blank field is safer than a confident but unsupported customer fact.

AI & agentsStack Overflow Blog

Agentic tools need process boundaries, not just faster output

Stack Overflow’s essay argues that developer tools earn trust by making workflows predictable, while agentic tools are faster, more opaque, and less predictable. Existing linters, tests, CI, and team habits encode an older development process, so validating AI-generated code can take longer even when production is faster.

Why read: A useful lens for evaluating agent products: reliability comes from clear boundaries and verification habits, not from output speed alone.

Acquisition websites get clearer when organized around user goals

Little Language Models recommends starting a multi-company website redesign with user goals rather than product ownership. Cross-company teams write goals for one another, group navigation and content around the actions users need to take, test labels and hierarchy with a small user group, and think horizontally about reusable content across pages.

Why read: The method turns a rebrand debate into an information-architecture exercise grounded in user jobs, which is a durable way to integrate multiple products.

Design & productHacker News / Karpathy

The Pelican benchmark is a useful test of spatial reasoning

Karpathy’s Pelican post sparked a large Hacker News discussion about whether models can build a convincing pelican-on-a-bike scene through code and spatial reasoning rather than a video-generation pipeline. Commenters split between treating it as a fun, difficult benchmark and arguing that the format is already saturated, but the disagreement points to the need for tests with visible room to improve.

Why read: A compact, inspectable visual task can expose consistency failures that polished generated media hides, making it more useful than a demo judged only by vibes.
